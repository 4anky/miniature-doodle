# Логово дракона

Пещера дышит жаром. Где-то в глубине, на груде сокровищ, лежит Главный Коммит.

Прежде чем входить, герой тренируется в отдельной ветке-полигоне `experiment/spells`:
пробует разные заклинания, и не все из них удачны. Огненный шар против огненного дракона —
так себе идея.

В книгу заклинаний (`spells.md`) должно попасть **только удачное** заклинание — ровно тот
коммит с полигона, без копирования текста руками.

Когда дракон будет повержен, Главный Коммит нужно пометить так, чтобы его нашёл любой
летописец: аннотированным тегом `v1.0.0`.
