# Тёмный лес

Тропа из деревни уходит в чащу. Здесь темно, сыро и пахнет плохими решениями.

На поляне растёт **проклятый гриб** (`cursed-mushroom.txt`). Пока он здесь, тропа не
откроется — его нужно уничтожить без следа в рабочей копии.

Дальше — **старый мост** через реку (`old_bridge.txt`). Лесничие давно хотят, чтобы описание
моста лежало в нормальном формате: `bridge.md`. Но если просто удалить старый файл и создать
новый, летописцы потеряют его историю. Переименуй его так, чтобы git понял: это тот же мост.

Под мостом живёт тролль. Он пропускает только тех, кто знает пароль. Загадка тролля:

> Я храню каждый шаг твоего пути,
> Покажу, кто, когда и зачем приходил.
> Назови команду из двух слов, что выводит меня на свет.

И последнее: в лесу без света не пройти. Положи в инвентарь факел.
