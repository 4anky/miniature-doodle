# Начальник стражи

— Стой! — начальник стражи поднимает алебарду. — Король читает только чистые летописи.

Он показывает на свиток (`scroll.md`).

— Допиши три строфы. Можешь писать по одной и коммитить хоть после каждой буквы — твоё
дело. Но в главную летопись это должно попасть **одним** аккуратным коммитом с
правильным заголовком. Принесёшь три коммита «wip», «ещё wip», «ну вот теперь точно» —
отправлю обратно.
