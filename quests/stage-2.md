# Этап 2. Тёмный лес

**Навыки:** несколько атомарных коммитов, `git rm`, `git mv`, история переименований.
**Ветка:** `quest/stage-2-forest`

## Легенда

Прочитай `world/forest/README.md`.

## Задание

Сделай **три отдельных коммита** — по одному на каждое действие:

1. **Факел.** Создай файл `inventory/torch.md` в формате из `inventory/README.md`
   (`Предмет: факел`). Коммит: `feat(inventory): взять факел`.
2. **Гриб.** Удали `world/forest/cursed-mushroom.txt` командой `git rm`.
   Коммит: `chore(forest): уничтожить проклятый гриб`.
3. **Мост.** Переименуй `world/forest/old_bridge.txt` в `world/forest/bridge.md` командой
   `git mv` и впиши ответ на загадку тролля вместо `???`.
   Коммит: `refactor(forest): перевести описание моста в markdown`.

Затем:

4. Убедись, что git видит переименование: `git log --follow --oneline -- world/forest/bridge.md`
   должен показать и коммиты, сделанные до переименования.
5. `tools/check.sh`, push, PR.
6. Смёржи PR кнопкой **Rebase and merge**, чтобы все три коммита попали в `main` по отдельности.

## Подсказки

<details>
<summary>Загадка тролля</summary>

Команда, которой ты только что смотрел историю моста, — без флагов.
</details>

<details>
<summary>Случайно сделал всё одним коммитом?</summary>

`git reset --soft HEAD~1` вернёт изменения в индекс, затем `git restore --staged <файл>`
уберёт лишнее, и можно коммитить по частям.
</details>

## Критерии прохождения

- в ветке минимум 3 коммита;
- гриба нет, `old_bridge.txt` переименован (git распознаёт это как rename), пароль верный;
- факел в инвентаре.
