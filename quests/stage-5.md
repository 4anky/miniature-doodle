# Этап 5. Логово дракона

**Навыки:** экспериментальная ветка, `git cherry-pick -x`, аннотированные теги, релиз.
**Ветки:** `experiment/spells` (не мёржится), `quest/stage-5-dragon`

## Легенда

Прочитай `world/dragon-lair/README.md`.

## Задание

### Часть 1. Полигон

1. Создай от свежего `main` ветку `experiment/spells`.
2. Добавь в конец `world/dragon-lair/spells.md` строку `- Огненный шар`.
   Коммит: `feat(dragon-lair): выучить огненный шар`.
3. Добавь следующей строкой `- Ледяное копьё`.
   Коммит: `feat(dragon-lair): выучить ледяное копьё`.
4. Запушь ветку (`git push -u origin HEAD`), но **PR не создавай** — это черновик.

### Часть 2. Бой

5. Вернись на `main` и создай ветку `quest/stage-5-dragon`.
6. Найди SHA коммита с ледяным копьём: `git log --oneline experiment/spells`.
7. Перенеси **только его**: `git cherry-pick -x <sha>`.
   Флаг `-x` допишет в сообщение строку `(cherry picked from commit ...)`.
8. Скорее всего, возникнет конфликт: коммит с копьём «помнит» строку с огненным шаром
   над собой. Разреши его — в файле должно остаться **только** `- Ледяное копьё` — и
   выполни `git add ...` и `git cherry-pick --continue`.
9. `tools/check.sh`, push, PR, merge.
10. Удали ветку `experiment/spells` на origin и локально — эксперимент окончен.

### Часть 3. Главный Коммит

11. Обнови `main` (`git pull --ff-only`).
12. Поставь аннотированный тег на вершину `main`:
    `git tag -a v1.0.0 -m "Гитландия спасена"`.
13. Запушь тег: `git push origin v1.0.0`.
14. (По желанию) Создай GitHub Release на основе тега: `gh release create v1.0.0 --generate-notes`.
15. Финальная проверка: `tools/check.sh final`.

## Вопросы для самопроверки

- Чем аннотированный тег отличается от лёгкого (`git tag v1.0.0`)?
- Почему cherry-pick создаёт новый коммит, а не «перемещает» старый?
- Когда в реальной работе нужен cherry-pick? (подсказка: hotfix в релизную ветку)

## Критерии прохождения

- в книге заклинаний есть ледяное копьё и нет огненного шара;
- коммит в ветке содержит отметку `cherry picked from commit`;
- финал: тег `v1.0.0` аннотированный, стоит на коммите из `main` и запушен на origin.
